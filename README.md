# 2026 천안시 청년정책 — 웹 프레젠테이션

첨부 PPTX 10장을 원본 레이아웃 그대로 웹에서 볼 수 있도록 변환한 정적 웹사이트입니다.

## 실행

- `index.html`을 브라우저에서 열거나 GitHub Pages에 배포하세요.
- 모든 이미지 파일과 `slides.js`는 `index.html`과 함께 올려야 합니다.
- 별도 서버, DB, 빌드 도구, CDN, 로그인은 필요 없습니다.

## GitHub Pages 게시

1. GitHub에서 새 저장소를 만듭니다 (예: `cheonan-youth-2026`).
2. 이 ZIP을 풀고 **폴더 안의 파일 전체**(`index.html`, `slides.js`, `slides.json`, `assets/`, `.nojekyll`)를 저장소 최상위에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. Branch는 **main**, 폴더는 **/(root)** 를 선택해 저장합니다.
5. 게시 주소: `https://계정명.github.io/cheonan-youth-2026/` (저장소 이름에 따라 달라집니다).

## 사용법

- 상단 **목차**: 10장 미리보기와 바로가기
- **이전 / 다음**: 화면 양쪽 버튼, 키보드 방향키, PageUp/Down, 스페이스
- **스크롤 / 스와이프**: 다음/이전 슬라이드 이동
- 상단 **정책 설명**: 원본 PPT의 발표자 노트, 확인사항, 출처 링크 표시
- **링크**: 현재 슬라이드 번호가 포함된 URL 복사 (`#slide-5` 등)
- **전체화면**: 화면 전체로 발표
- 2번 정책지도 카드 클릭: 관련 정책 슬라이드로 바로가기

## 구현 및 콘텐츠 관련

- 슬라이드 본문은 원본 디자인 보존을 위해 고화질 WebP 이미지로 표시됩니다. 본문 텍스트의 개별 직접 수정은 원본 PPTX에서 수행해야 합니다.
- 텍스트 기반 정책 설명과 출처는 `slides.js`에 포함되어 있습니다. `slides.json`에는 동일한 구조화 데이터가 별도로 제공됩니다.
- 원본 발표자 노트의 정책 구분, 확인 필요 사항, URL을 유지했습니다. 모집 현황은 게시 전에 재확인하세요.
- 슬라이드 이미지 및 데이터의 소유권·게시 권한을 확인한 후 공개하세요.
